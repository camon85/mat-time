# DR-001. 병합 판정에 쓸 "켠 시각"을 항목마다 저장한다

- **날짜**: 2026-08-07
- **상태**: 결정됨

## 맥락

동기화 병합은 항목마다 `(살아있음/지워짐, 시각)` 을 만들어 늦은 쪽을 채택한다.
지워진 쪽 시각은 툼스톤(`removed` 등)에 있는데, **살아있는 쪽 시각**은 저장하지 않고
문서의 `updatedAt` 으로 대신하고 있었다.

그 근사가 실제로 깨진다. 문서 시각은 그 기기의 **마지막** 변경 시각이라, 무엇이든 하나 고치면
살아 있는 **모든** 항목의 주장 시각이 함께 밀려 상대의 툼스톤을 통째로 이긴다.

```
폰:  8/1 출석 취소 (8/2 09:00) → Gist push
PC:  아직 동기화 안 함. 8/5 에 열어서 8/5 만 새로 체크
PC:  동기화 → 8/1 의 주장 시각도 8/5 가 되어 취소를 이김 → 8/1 부활
```

「폰에서 지우고 나중에 PC 를 연다」는 멀티기기의 기본 흐름이다. 기존 문서는 이걸
"남는 모호함(실사용에서 문제된 적 없음)" 으로 적어 두었는데, 재현해 보니 흔한 경로였다.
출석·승급 이력·분류가 모두 같은 함수를 타므로 셋 다 같은 증상을 갖는다.

## 검토한 선택지

### 옵션 A: 항목마다 시각 저장 (전량)
출석은 `checked: {날짜: ISO}` 병렬 맵, 승급 이력·분류는 항목에 `at` 필드.
옛 문서를 읽을 때 문서의 `updatedAt` 으로 한 번 채워 확정한다.

- 장점: 규칙이 하나가 된다 — 메모(`notes[d].at`)가 이미 쓰던 방식과 완전히 같아진다.
  옛 데이터도 읽는 즉시 고쳐지고, 마이그레이션 코드가 필요 없다
- 단점: 코어 문서가 **3.3~3.5배** (10년 30 KB → 100 KB). 출석 한 번 탭할 때 올리는 양도 그만큼

### 옵션 B: 최근 것만 저장하고 오래된 것은 정리
마지막 동기화 이후 켠 날짜만 시각을 갖고, 동기화가 성공하면 정리한다.

- 장점: 크기 증가가 거의 없다
- 단점: **정리한 순간 그 날짜는 다시 문서 시각으로 떨어진다.** 툼스톤은 영구히 남으므로
  오래된 툼스톤이 정리된 날짜를 이겨 **멀쩡한 출석이 사라질 수 있다.**
  버그의 방향이 「되살아남」에서 「없어짐」으로 바뀌는데, 후자가 더 나쁘다

### 옵션 C: 툼스톤을 우선하는 보수적 판정
시각이 없으면 툼스톤이 이기게 한다.

- 장점: 코드 한 줄, 크기 증가 0
- 단점: 마이그레이션 이전에 켠 날짜가 옛 툼스톤에 져서 사라진다. B 와 같은 방향의 손실

## 고민 과정

크기가 유일한 쟁점이었다. 재 보니 최악(매일 × 30년)에도 687 KB 로 Gist 의 1 MB inline
임계 아래이고, 넘더라도 `readGistFile()` 이 `raw_url` 로 우회하므로 동작은 같다.
문서를 코어/메모로 나눠 둔 덕에 출석 경로는 여전히 메모 문서의 1/10 수준이다.

B·C 는 크기를 아끼는 대신 **실패의 방향을 데이터 손실 쪽으로 돌린다.** 되살아난 출석은
눈에 보이고 다시 지우면 되지만, 사라진 출석은 사용자가 알아채지도 못한다.
이 앱에서 지켜야 할 것은 「기록이 없어지지 않는 것」이므로 교환이 성립하지 않는다.

## 결정

**옵션 A** 채택.

채택 이유: 크기 3배는 실측상 어떤 한계선에도 닿지 않는 반면, B·C 는 버그를 「부활」에서
「소실」로 바꿀 뿐이다. 덤으로 메모가 쓰던 규칙과 하나로 합쳐져 병합 코드가 단순해진다.

## 영향

- 코어 문서에 `checked` 추가, `history[i].at` · `tags[i].at` 추가
  ([`data-format.md`](../data-format.md) §3 · §7)
- **빈 시각은 저장하지 않는다** — 값이 없으면 키/필드 자체를 넣지 않는다.
  첫 실행처럼 문서 시각조차 없을 때 `at: ""` 를 남기면 그 문서를 내보낸 백업이
  자기 검증에 걸린다 (스모크 테스트가 잡았다)
- 옛 백업은 이 필드들 없이도 복원된다 — 검증에서 **선택 항목**으로 둔다
- `sameState` 에 `checked` 를 넣어야 한다. 빠뜨리면 고쳐도 Gist 에 올라가지 않는다
- 회귀 테스트를 남겼다 (`test/merge.test.mjs` — "회귀:" 로 시작하는 셋)
- 남는 한계: 시계가 크게 어긋난 기기, 그리고 정리되지 않는 툼스톤 (§7.2)
