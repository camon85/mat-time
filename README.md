# Mat Time

주짓수 출석 트래커. 체육관 승급 최소 기준(수련 기간 + 출석 일수)에 대한 진행도를 추적하는 정적 웹앱.
서버·빌드·의존성 없이 `index.html` · `styles.css` · `app.js` 세 파일로 동작한다.

## 승급 최소 기준

| 구간 | 수련 기간 | 출석 일수 |
|---|---|---|
| 화이트 0그랄 → 4그랄 (4단계) | 3개월 | 30일 |
| 화이트 4그랄 → 블루, 이후 블랙까지 전 단계 (16단계) | 7개월 | 90일 |

두 조건을 **모두** 충족해야 하므로 종합 진행률은 둘 중 낮은 쪽으로 표시한다.
화이트 0그랄부터 블랙벨트까지 총 20단계.

**승급식은 매월 마지막 금요일**이다. 기준을 채운 날 바로 승급하는 게 아니라
그 뒤 처음 오는 승급식에 올라간다. 앱은 목표 승급식 날짜와 D-day 를 함께 보여준다.

## 기능

- 오늘 출석 체크 (버튼 한 번, 다시 누르면 취소)
- 지난 날짜 출석 체크 (캘린더에서 날짜 탭, 미래 날짜는 비활성)
- 다음 승급까지 진행도 — 기간 / 출석 일수 각각 + 종합, 목표 승급식 D-day
- 블랙벨트까지 전체 로드맵
- 승급 기록 — 현재 벨트·단계 시작일이 여기서 파생 (과거 출석 기록은 보존)
- 주짓수 시작일 기록 → 총 수련 기간 표시 (옵셔널)
- JSON 백업 / 복원, 깃허브 Gist 동기화 (옵셔널)

## 승급 기록 = 현재 상태

**현재 벨트·그랄과 단계 시작일을 따로 설정하는 곳은 없다.** 승급 이력의 가장 최근 항목이
곧 지금 상태이고, 그 날짜부터 다음 승급 기준을 센다 — 승급일과 단계 시작일은 같은 사실이다.

설정 → 승급 이력 → **＋ 승급 기록** 에서 `승급일` · `받은 벨트` · `받은 그랄` 을 넣는다.
기본값은 **오늘 + 다음 그랄**이라, 오늘 받았으면 열어서 바로 기록하면 된다.
처음 쓸 때는 마지막으로 승급한 날을 기록하면 현재 벨트가 맞춰진다.

- 이력이 비어 있으면 화이트 0그랄로 보고, 기준일은 주짓수 시작일(없으면 오늘)
- 미래 날짜도 기록할 수 있다 (「승급 예정」으로 표시)
- 같은 날짜를 다시 기록하면 기존 항목을 교체한다 (확인 후)
- 기록한 날짜는 캘린더에 주황색 점으로 표시된다
- 항목을 **삭제**하면 자동으로 직전 상태로 돌아간다. 되돌리기 버튼이 따로 없는 이유다
- 출석 기록은 어느 경우에도 지워지지 않는다

## 주짓수 시작일

설정의 유일한 직접 입력값. 처음 도장에 등록한 날이며 「기록」 카드에 `6년 5개월째` 로 표시된다.
**승급 계산에는 쓰이지 않고**, 비워 둬도 된다.

동기화 시 이 값만은 "최신 우선"이 아니라 **더 이른 날짜**를 채택한다.
시작일은 가장 이른 기록이 진실이므로, 한쪽 기기에만 입력해도 지워지지 않는다.

## GitHub Pages 배포

정적 파일뿐이라 빌드 과정이 없다. 아래 순서로 진행한다.

### 1. GitHub에 저장소 생성

[github.com/new](https://github.com/new) 에서 저장소를 만든다. 이름은 `mat-time`.
공개(Public) 저장소면 Pages 가 무료다. Private 은 유료 플랜에서만 Pages 를 쓸 수 있다.

> 이 앱은 출석 날짜만 다루고 그것도 브라우저에만 저장되므로,
> 저장소를 공개해도 개인 기록이 노출되지 않는다. 코드만 공개된다.

### 2. 푸시

로컬 저장소와 초기 커밋은 이미 만들어져 있다. 원격만 연결해 푸시하면 된다.

```bash
git remote add origin https://github.com/<사용자명>/mat-time.git
git push -u origin main
```

### 3. Pages 활성화

저장소 → **Settings** → **Pages** →
- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)`
- Save

1~2분 뒤 `https://<사용자명>.github.io/mat-time/` 에서 접속된다.

### 4. 폰에 설치

위 주소를 폰 브라우저로 연 뒤
- iOS Safari: 공유 → **홈 화면에 추가**
- Android Chrome: 메뉴 → **홈 화면에 추가**

주소창 없이 전체화면으로 뜬다.

### 이후 수정 반영

```bash
git add -A && git commit -m "수정 내용" && git push
```

푸시하면 1분 내에 자동 반영된다.

## 데이터 저장 위치

기본은 브라우저 **localStorage** (`bjj-attendance` 키). 다음을 뜻한다.

- 데이터는 **그 기기의 그 브라우저에만** 있다. 서버로 전송되지 않는다.
- 기기·브라우저를 바꾸면 기록이 따라오지 않는다.
- 브라우저 데이터 삭제, 시크릿 모드 종료 시 사라진다.
- iOS Safari 는 7일 이상 방문하지 않은 사이트의 저장 데이터를 자동 삭제할 수 있다
  (홈 화면에 추가해 두면 이 정책에서 제외된다).

대응책은 두 가지다. 아래 **동기화**를 켜거나, **설정 → 백업(JSON)** 으로 파일을 받아 두는 것.

## 기기 간 동기화 (GitHub Gist)

서버 없이 기록을 여러 기기에서 공유하는 선택 기능이다. 켜지 않아도 앱은 그대로 동작한다.

### 원리

깃허브 개인 토큰으로 브라우저가 **비공개 Gist** 하나를 직접 읽고 쓴다.
중간 서버가 없고, 기록은 본인 깃허브 계정에만 저장된다.

### 설정

1. 설정 패널의 **토큰 발급 →** 링크를 연다 (`gist` 권한만 체크된 상태로 열린다)
2. 만료 기간을 고르고 토큰 생성 → 값 복사
3. 앱의 **깃허브 토큰** 칸에 붙여넣고 **연결**

Gist 는 자동 생성된다. 다른 기기에서 같은 토큰을 넣으면 그 Gist 를 찾아 기록을 이어받는다.

### 동기화 시점

- 출석 체크·설정 변경 후 1.5초 (디바운스)
- 앱을 열거나 다시 활성화할 때
- **지금 동기화** 버튼

### 병합 규칙

| 항목 | 규칙 |
|---|---|
| 출석 날짜 | 날짜마다 **켠 시각 vs 끈 시각**을 비교해 늦은 쪽 — 추가도 취소도 전파된다 |
| 승급 이력 | 날짜 기준 합집합 (현재 벨트는 여기서 파생) |
| 주짓수 시작일 | 더 이른 날짜 |
| 초기화 · 복원 | 병합하지 않고 Gist 를 **덮어쓴다** |

취소한 날짜는 취소 시각과 함께 남겨 두기 때문에 다른 기기로도 삭제가 전파된다.
자세한 규칙은 [`docs/data-format.md`](docs/data-format.md) §7 참조.

### 토큰 취급

- 토큰은 `bjj-attendance-sync` 키에 **기록과 분리**해 저장되며, JSON 백업 파일에 포함되지 않는다
- `gist` 권한만 있으므로 유출되어도 저장소·계정 설정에는 접근할 수 없다
- 공용 PC 에서는 쓰지 말고, 필요하면 **연결 해제** 또는 깃허브에서 토큰을 폐기한다
- 비공개(secret) Gist 는 검색에 노출되지 않지만 URL 을 아는 사람은 볼 수 있다 — 완전한 비공개는 아니다

## 파일 구성

```
index.html            마크업
styles.css            스타일
app.js                로직 (상태·계산·렌더·동기화)
docs/data-format.md   데이터 포맷 명세
.nojekyll             GitHub Pages 의 Jekyll 전처리 비활성화
README.md             이 문서
```

저장 데이터의 스키마·병합 규칙·파생 계산식은 [`docs/data-format.md`](docs/data-format.md) 에 따로 정의했다.
이 데이터로 다른 앱을 만들거나 스크립트로 분석할 때 그 문서만 보면 된다.

빌드 도구·번들러·의존성이 없다. 파일을 그대로 올리면 그대로 동작한다.

`app.js` 는 일반 스크립트(`<script src>`)로 불러온다. ES 모듈(`type="module"`)로 바꾸면
`file://` 로 열 때 CORS 정책에 걸려 로드되지 않으므로, 더블클릭으로 여는 사용을 유지하려면
모듈로 바꾸지 말 것.

### 설정 패널 순서

수련 데이터를 위에, 저장·백업을 아래에 둔다.

```
주짓수 시작일                                ← 유일한 직접 입력값
승급 이력                                    ← 현재 벨트·단계 시작일의 원천
기기 간 동기화 (GitHub Gist)                 ← 저장
백업 / 복원
전체 초기화
```
