# dev/ — 로컬 테스트용

앱 동작에는 쓰이지 않는다. `index.html` 이 이 폴더를 참조하지 않으므로
GitHub Pages 에 함께 올라가도 영향이 없다.

| 파일 | 내용 |
|---|---|
| [`sample-data.json`](sample-data.json) | 앱의 **설정 → 복원** 에 넣는 샘플 백업 |
| [`gen-sample.py`](gen-sample.py) | 그 파일을 만드는 생성기 |
| [`shots.py`](shots.py) | README 용 스크린샷을 `docs/images/` 에 다시 만든다 |

## 쓰는 법

앱을 열고 **설정 · 승급 이력 · 백업** → **복원** → `dev/sample-data.json` 선택.
현재 기록을 덮어쓰므로, 실제 기록이 있다면 먼저 **백업(JSON)** 을 받아 두자.

```
python3 dev/gen-sample.py                  # 오늘 기준으로 다시 만든다 (10개월치)
python3 dev/gen-sample.py --months 36      # 3년치
python3 dev/gen-sample.py -o 다른경로.json
```

**연·월 그룹과 연도 점프는 여러 해에 걸친 데이터가 있어야 보인다.** 기본 10개월치로는
연도 칩이 하나뿐이라 점프바가 아예 숨는다 — 그 화면을 보려면 `--months 36` 이상으로 만들자.

날짜를 전부 **오늘 기준 상대**로 계산한다. 그대로 두면 시간이 지날수록
「현재 단계 4.4개월」 같은 값이 밀리므로, 오래된 파일은 다시 생성해 쓰는 편이 낫다.

## 담긴 상태

7년차 퍼플 2그랄. 화면 요소를 골고루 건드리도록 값을 맞췄다.

| 항목 | 값 | 무엇을 확인하려고 |
|---|---|---|
| 승급 이력 | 12건 (화이트 1그랄 ~ 퍼플 2그랄) | 이력 목록 · 로드맵 · 달력의 승급일 점 |
| 출석 | 115일 · 10개월 전부터 | 잔디 왼쪽의 **「기록 전」 구간** (앱을 늦게 시작한 경우) |
| 현재 단계 | 55/90일 · 4.4/7개월 → **61%** | 두 막대가 모두 미달이라 **빠르면 / 이 페이스면** 예측이 갈라진다 |
| 공백 | 부상·휴가 3회 | 연속 주가 끊긴 상태 |
| 메모 | 35개 (이번 달 4개 포함) | 달력 아래 목록이 비어 보이지 않게 이번 달을 먼저 채운다 |
| 분류 | 기본 5종 + 노기 · 오픈매트 | 사용자가 추가한 분류의 병합·필터 |

`--months 36` 이면 출석 424일 · 메모 126개 · 연도 4개가 되어 연·월 그룹과 점프바까지 확인된다.

`validateBackup()` 을 통과하도록 만들어져 있다 — 통과하지 못하면 복원 자체가 거부되므로,
이 파일이 들어간다는 것 자체가 형식이 온전하다는 증거다.

## 스크린샷

```
python3 dev/shots.py        # docs/images/*.png 를 다시 만든다
```

3년치 샘플을 **앱의 복원 경로로 넣은 뒤** 찍으므로 화면 값이 실제 계산 결과다.
날짜가 오늘 기준 상대라 시간이 지나면 「4.4 / 7개월」 같은 값이 밀린다 —
README 를 손볼 때 함께 다시 돌리면 된다.

`playwright` 가 필요하다: `pip install playwright && playwright install chromium`
